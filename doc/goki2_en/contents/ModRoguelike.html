roguelike_option (No alias)

Basic Settings
AliasAttributeRequired?ValueDescription
Nonedebugnotrue or falseToggles debug mode ON/OFF.
Nonedebug_dump_mapnotrue or falseIf set to true, map information will be output to the console.
Nonestairs_downnotrue or falseIf set to true, descending stairs will be placed at the specified (x, y) position.
Nonestairs_upnotrue or falseIf set to true, ascending stairs will be placed at the specified (x, y) position.
NonexnoGrid unitsSpecifies the X-coordinate for placing stairs.
NoneynoGrid unitsSpecifies the Y-coordinate for placing stairs.
Noneroom_count_minnoIntegerSpecifies the minimum number of rooms to be placed per floor.
Noneroom_count_maxnoIntegerSpecifies the maximum number of rooms to be placed per floor.
Noneitem_count_minNoIntegerSpecifies the minimum number of items to place on one floor.
Noneitem_count_maxNoIntegerSpecifies the maximum number of items to place on one floor.
Nonegrid_widthnoPixelsSpecifies the grid size in pixels. Default is 64.
Nonegrid_heightnoPixelsSpecifies the grid size in pixels. Default is 64.
Nonemap_widthnoGrid unitsSpecifies the map width in grid units. Default is 10.
Nonemap_heightnoGrid unitsSpecifies the map height in grid units. Default is 10.
Noneinitial_room_indexno0-based indexSpecifies the index of the initial room to be displayed.
Nonemax_floornoIntegerSpecifies the maximum depth (number of floors) the player can descend.
NonemessagenoLayer nameSpecifies the name of the message layer used for displaying messages.
Nonemessage_intervalnoMillisecondsSpecifies the time in milliseconds to hide the message layer used for displaying messages.
Configures the basic settings for the roguelike game.

roguelike_stairs_event (No alias)

Stair Events.
AliasAttributeRequired?ValueDescription
NonenameyesStair NameSpecifies the name of the stairs defined in roguelike_load_chips.
NonestoragenoScenario file nameSpecifies the scenario file to execute upon entering the stairs. This runs every time the stairs are entered. To remove the event, specify "void" for this attribute. Executing this event will not automatically trigger a floor transition. To move to the next floor, call the roguelike tag with the next_floor attribute.
NonetargetnoLabel nameSpecifies the label within the scenario to execute upon entering the stairs. This runs every time the stairs are entered. To remove the event, specify "void" for this attribute. Executing this event will not automatically trigger a floor transition. To move to the next floor, call the roguelike tag with the next_floor attribute.
Configures event triggers for stairs.
