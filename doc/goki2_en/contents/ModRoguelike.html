Basic Settings
AliasAttributeRequired?ValueDescription
Nonedebugnotrue or falseToggles debug mode ON/OFF.

Nonedebug_show_trapnotrue or falseSpecifying true will display traps.
Nonedebug_trapnotrue or falseSpecifying true will output trap logs to the console.
Nonefont_sizenoInteger valueSpecifies the font size.
Nonefontnotrue or falseSpecifies the font name.
Nonestairs_downnotrue or falseIf set to true, descending stairs will be placed at the specified (x, y) position.

NonexnoGrid unitsSpecifies the X-coordinate for placing stairs.
NoneynoGrid unitsSpecifies the Y-coordinate for placing stairs.
Noneroom_count_minnoIntegerSpecifies the minimum number of rooms to be placed per floor.

Nonemonster_house_enemy_maxnoIntegerSpecifies the maximum number of enemies to place in a monster house.

Nonemonster_house_item_maxnointeger valueSpecifies the maximum number of items to place in the monster house.
Nonemonster_house_trap_minNoIntegerSpecifies the minimum number of traps to place in a monster house.
Nonemonster_house_trap_maxNoIntegerSpecifies the maximum number of traps to place in a monster house.
Noneenemy_sleepingno0-100Specifies the probability that an enemy will appear in a sleeping state.

Nonegrid_widthnoPixelsSpecifies the grid size in pixels. Default is 64.
Nonegrid_heightnoPixelsSpecifies the grid size in pixels. Default is 64.

Nonemessage_layer_namenoLayer nameSpecifies the name of the message layer used for displaying messages.
Nonemessage_intervalnoMillisecondsSpecifies the time in milliseconds to hide the message layer used for displaying messages.
Nonecorrection_value_minnoIntegerSpecifies the minimum correction value for ranged weapons, inserted items, etc.
Nonecorrection_value_maxnoIntegerSpecifies the maximum correction value for ranged weapons, inserted items, etc.
NonemessagenostringSpecifies the message to display.
Nonemessage_auto_hideNotrue or falseIf true is specified, the message will automatically be hidden after the specified number of seconds.
If false, the message remains displayed until explicitly hidden.
Nonehide_messagenotrue or falseIf true, hides the message.
