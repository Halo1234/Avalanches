modresult Tags

This is the reference for tags available in modresult.
To load and display backgrounds or decorations, please use modimage.
This module is specifically for displaying scores.

Category / Tag List


result_score_layersSpecify the number of layers for displaying the score
resultSettings for the result screen
wait_show_resultWait for the score layer to be displayed
wait_hide_resultWait for the score layer to be hidden


result_score_layers (No alias)

Sets the number of layers for score display
AliasAttributeRequired?ValueDescription
NonecountnoInteger (1 or more)Specifies the number of layers for score display.
NonebasenoInteger (0 or more)The base "absolute" value for the score display layers.
NonestepnoInteger (1 or more)Specifies the step value for score display layers.
The value specified here will be added to the "absolute" value sequentially.
Defines the number of layers for score display.

result (No alias)

Configure score display layer settings
AliasAttributeRequired?ValueDescription
NonelayernoScore layer nameSpecifies the name of the score layer.
Value ranges from 0 to n (where n is the number of layers specified in result_score_layers - 1).
Nonecenter_xnoPixel unitsSpecifies the horizontal center position of the score display layer.
Nonecenter_ynoPixel unitsSpecifies the vertical center position of the score display layer.
NoneleftnoPixel unitsSpecifies the X-coordinate (top-left) of the score display layer.
NonetopnoPixel unitsSpecifies the Y-coordinate (top-left) of the score display layer.
NonerightnoPixel unitsSpecifies the X-coordinate (bottom-right) of the score display layer.
NonebottomnoPixel unitsSpecifies the Y-coordinate (bottom-right) of the score display layer.
NonewidthnoPixel unitsSpecifies the width of the score display layer.
NoneheightnoPixel unitsSpecifies the height of the score display layer.
Nonecolorno0xrrggbbSpecifies the background color of the score display layer.
Noneopacityno0-255Specifies the opacity of the score display layer.
Nonecaption_alignnoPixel / String"left": Left-aligned.
"right": Right-aligned.
"center": Centered.
Numerical values will specify an offset.
Nonecaption_colorno0xrrggbbSpecifies the text color of the score value.
Noneshadow_colorno0xrrggbbSpecifies the shadow color of the score value.
Noneedge_colorno0xrrggbbSpecifies the edge color of the score value.
Nonefont_facenoFont nameSpecifies the font name for score display.
Nonefont_sizenoPixel unitsSpecifies the font size for score display.
Noneseparatornotrue or falseIf true is specified, digit grouping symbols will be displayed in the score.
NonescorenoScore valueSpecifies the score value to be displayed.
It is assumed that an entity will be specified here.
ModPuzzle Score (User 1): &window.modules.modPuzzle.baseLayer.puzzleUserLayer1.score
ModPuzzle Score (User 2): &window.modules.modPuzzle.baseLayer.puzzleUserLayer2.score
ModTypingProcessor Score: &window.modules.modTypingProcessor.baseLayer.totalScore
ModTypingProcessor Number of Mistyped Entries: &window.modules.modTypingProcessor.baseLayer.missHit
ModTypingProcessor Number of Characters Entered: &window.modules.modTypingProcessor.baseLayer.inputCharacterCount
NonetimenomsSpecifies the duration of the score display effect in milliseconds.
Nonecompleted_storagenoStorage nameSpecifies the scenario file to execute after the score display and hiding process is complete.
Nonecompleted_targetnoLabel nameSpecifies the label to jump to after the score display and hiding process is complete.
Noneshownotrue or falseIf set to true, starts displaying the score.
Nonehidenotrue or falseIf set to true, starts hiding the score display.
Noneshow_hide_typenovista or fadeSpecifies the type of display effect.
Configures the score layer.
