Reference for tags available in ModPuzzle.
The plugins required by this module are BlueMonday-88.dll and (if playing online) Fischerspooner.dll.
This module requires ModSound.

Please call the following in the puzzle piece animation file:

Call the following at the end of the landing animation:

[call_handler message=onLanding]

Call the following at the end of the erase animation:

[call_handler message=onErase]

Several events are defined in the puzzle piece animation script:

LabelDescription
*waitingImplements the waiting animation.
*landingImplements the landing animation.
*eraseImplements the erase animation.
